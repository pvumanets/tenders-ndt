## Уровни

| Тир | Имя на доске | Смысл | Карточка rostender |
| --- | --- | --- | --- |
| **L1** | Горячие | Явная **услуга / работа** НК (проведение контроля, не закупка железа) | да |
| **L2** | Сильные | Услуга НК видна, сигнал чуть слабее | да |
| **L3** | Смотреть | Пограничные **или** поставка / калибровка / приборы / расходники | да |
| `noise` | Шум | Явно не наше (обучение как единственный предмет и т.п.) — вне доски L1–L3 по политике ingest | нет |
| `pool` | Прочий пул | В выдаче, не L1–L3 и не явный noise | нет |
| *(колонка)* | **Просроченные** | Бывший L1–L3 со сроком подачи &lt; сегодня МСК — не тир скоринга, см. lifecycle | — |

Карточки площадки для обогащения открываем **для кандидатов L1–L3** (после первичного score по строке списка). Просрочка — отдельный столбец доски, не новый тир score.

После правил лот попадает на доску в **L1 / L2 / L3** (ingest/inbox по `tier`, не только score≥4). **ИИ — отдельный шаг** после прогона — см. [`ai-tier-review.md`](./ai-tier-review.md).

## Жёсткие правила предмета (важнее «набранных баллов»)

### Всегда «Смотреть» (L3), даже если в тексте много слов про НК

Если предмет — в первую очередь:

- **поставка / закупка / поставка оборудования** для НК;
- **приборы**, дефектоскопы, толщиномеры, сканеры как товар;
- **калибровка / поверка СИ** без оказания услуг контроля на объекте;
- **расходники**, плёнка, купоны, эталоны как товар;

→ тир-кандидат **L3 (Смотреть)**. Нельзя поднимать в Горячие/Сильные только из‑за «неразрушающий» / «УЗК» в названии оборудования.

**Строительный контроль / соцобъекты / кровля:** не «всегда L3» в скоринге. Отсев контекстного мусора — **минус-фразы на пакете D** ([`search-system-v2.md`](../discovery/search-system-v2.md)). Hard rule 035 (`is_construction_watch`) — **deprecated**, откат при коде 036.

**Плохой пример (не Горячие):** «Поставка непроектного оборудования для неразрушающего контроля …» при score с тегами услуги — всё равно **Смотреть**.

### Горячие / Сильные — только работы и услуги

Если предмет — **оказание услуг / проведение контроля** (сварные соединения, трубопроводы, металлоконструкции и т.д.) → кандидат L1 или L2 по силе сигнала, **не** L3 «потому что осторожно».

## Эталоны владельца (2026-08-26)

1. **«Проведение неразрушающего контроля сварных соединений»** → **Горячие (L1)**. Явная услуга проведения НК + объект (сварные соединения). Не оставлять в Сильных «на всякий случай».

2. **«Оказание услуг по проведению экспертизы промышленной безопасности по определению толщины стенок трубопроводов … методом неразрушающего контроля …»** → **наш интерес, L1 или L2**: услуги, связанные с контролем **толщины стенок** / **трубопроводов** методом НК. В правилах и промпте ИИ **запрещено** кодировать фильтр по **классу опасности** / допускам — это отдельная ручная оценка директора, не автоматика (явный запрет владельца: иначе будут ошибки).

## Критерии L1 / L2 / L3 (услуги)

### L1 — Горячие

Услуга НК **и** сильный сигнал, например:

- УЗК/УЗТ **как работы** (не прибор; не «УК» управляющей компании — [033](./tasks/033-no-uk-rk-keywords.md));
- радиограф / рентген / гамма / ЦР как **проведение** контроля (не голая аббревиатура «РК»);
- «проведение НК» / «неразрушающий контроль» + объект (нефтегаз, энергетика, стройка, промплощадка);
- контроль толщины / трубопроводов как **услуги** (эталон 2);
- желательно статус «Приём заявок» и живой срок (иначе колонка Просроченные).

Ориентир score: **≥ 6** или явное УЗК-услуга при score ≥ 4 — **если** не сработали правила «всегда Смотреть».

### L2 — Сильные

Явная услуга НК (ВИК/ПВК/НК/дефектоскопия как работы), но без «идеальной» связки метод+объект; или смешанный предмет с **доминирующей услугой** (не поставкой железа).

Ориентир: score **4–5**, и снова не оборудование.

### L3 — Смотреть

- Пограничная услуга / неоднозначный предмет **или**
- любое попадание под блок «всегда Смотреть» выше.

Ориентир для пограничных услуг: score **2–3** без exclude; для поставки приборов — L3 **независимо** от высокого «словного» score.

### noise

Только обучение/аттестация как единственный предмет, явный нерелевант вне НК — **вне доски** (noise). Поставка приборов НК — на доске в **Смотреть (L3)**.

### Ingest / inbox (lock 2026-08-27)

На доску попадают лоты с **`tier ∈ {L1, L2, L3}`**. Порог score≥4 alone **не** используется для фильтра inbox после sync кода.

## Правила → доска; ИИ → отдельный шаг

| Шаг | Что делает |
| --- | --- |
| 1. Правила (прогон) | Тир L1/L2/L3 + теги; жёсткая поставка → L3; явная услуга → L1/L2 → **на доску** |
| 2. ИИ (**по команде**) | Оператор запускает «Разобрать с ИИ»; модель правит/подтверждает тир + `reason_ru` → раздел «Разобрано с помощью ИИ» |

Смесь сигналов и слабые формулировки — зона ИИ после того, как лот уже на доске по правилам. Детали → [`ai-tier-review.md`](./ai-tier-review.md).

**Не кодировать в правилах:** класс опасности объекта, наличие/отсутствие допусков лаборатории.

## Артефакты

Один файл с секциями (предпочтительно):

```text
runs/YYYY-MM-DD/priority-fit.md
```

Секции `## L1`, `## L2`, `## L3` + таблица в каждой.  
Опционально отдельные `priority-l1.md` … если удобнее.

Excel: лист `fit` с колонкой `tier` ∈ {L1,L2,L3} или три листа.

Полный пул прогона: `tenders.md` / `tenders.xlsx` с колонкой `tier` (без потолка 1000 — lock 2026-08-27).

Формат строки — как в [`../discovery/output-schema.md`](../discovery/output-schema.md); вместо `ideal_reason` → `fit_reason`.
