## Уровни

| Тир | Имя | Смысл | Карточка rostender |
| --- | --- | --- | --- |
| **L1** | Горячие | Явная услуга НК / УЗК, объект, желательно живой приём | да |
| **L2** | Сильные | Услуга НК видна, сигнал чуть слабее | да |
| **L3** | Смотреть | Пограничные, не приборы; нужна проверка человеком | да |
| `noise` | Шум | Приборы, расходники, обучение как предмет | нет |
| `pool` | Прочий пул | В 1000, не L1–L3 и не явный noise | нет |

Карточки открываем **только для L1–L3** (после первичного score по строке списка).

---

## Критерии (черновик; дообучение после выгрузок)

### L1

Услуга НК **и** сильный сигнал, например:

- УЗК/УК/УЗТ **как работы** (не прибор) — владелец: забираем;
- или РК/ЦР/гамма/рентген как проведение контроля;
- или «проведение НК» + объект (нефтегаз, энергетика, стройка, промплощадка);
- желательно статус «Приём заявок».

Ориентир score: **≥ 6** или явное УЗК-услуга при score ≥ 4.

### L2

Явная услуга НК (ВИК/ПВК/НК/дефектоскопия как работы), но без «идеальной» связки метод+объект+срок; или смешанный предмет с доминирующей услугой.

Ориентир: score **4–5**.

### L3

Слово «неразрушающий» / НК в названии, предмет неоднозначен, но **не** похож на закупку прибора; человек должен глянуть.

Ориентир: score **2–3** без exclude-сигналов.

### noise

Закупка/поставка приборов, поверка СИ без услуг, только расходники, только обучение/аттестация как предмет. Score с сильным минусом.

## Артефакты

Один файл с секциями (предпочтительно):

```text
runs/YYYY-MM-DD/priority-fit.md
```

Секции `## L1`, `## L2`, `## L3` + таблица в каждой.  
Опционально отдельные `priority-l1.md` … если удобнее.

Excel: лист `fit` с колонкой `tier` ∈ {L1,L2,L3} или три листа.

Полный пул 1000: `tenders.md` / `tenders.xlsx` с колонкой `tier`.

Формат строки — как в [`../discovery/output-schema.md`](../discovery/output-schema.md); вместо `ideal_reason` → `fit_reason`.
