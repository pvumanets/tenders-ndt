## Проблема

Скоринг занижает явные услуги НК и завышает поставку/калибровку в Горячие/Сильные. ИИ нельзя вешать на каждый ingest — владелец хочет **контроль**: сначала правила, потом отдельный шаг «Разобрать с ИИ».

## Решение

1. Жёсткие правила → тир **L1/L2/L3**; ingest/inbox по **`tier ∈ {L1,L2,L3}`** (не только score≥4).
2. Поставка / приборы / калибровка → **L3**; явная услуга → L1/L2.
3. **Прогон без ИИ** — лоты сразу на доске по правилам.
4. **ИИ (provod.ai)** — **отдельное действие** «Разобрать с ИИ»; раздел «**Разобрано с помощью ИИ**»; журнал «ИИ ошибся».
5. Цепочка моделей на **одном** provod.ai; сбой → `ai_error`, tier правил **не** меняется молча.
6. `reason_ru` в drawer после успешного ИИ.
7. **Запрет:** класс опасности / допуски в правилах и промпте.
8. **Мусор страховки (пакет E):** ИИ обязан не пускать обучение / железо / нерелевант в Горячие.

### Эталоны

- «Проведение неразрушающего контроля сварных соединений» → **L1**
- Услуги по **толщине стенок** / **трубопроводов** методом НК → **L1 или L2**
- «Поставка оборудования для НК» → **L3**
