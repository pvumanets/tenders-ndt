**status:** draft  
**last-review-date:** 2026-08-11

## Факт из ресёрча

По [`platform-api-research.md`](../platform-api-research.md) § РосТендер:

- На [rostender.info/export](https://rostender.info/export) **запрещено** автоматизированное извлечение данных без официального разрешения ООО «Тендеры и закупки».
- Есть путь по подписке: API и интеграции **Bitrix24 / amoCRM**.

## Решение владельца на discovery

Осознанно фиксируем **UI-прототип** на демо-доступе как эксперимент discovery/следующего этапа кода. Это **не** утверждённый прод-контур и **не** замена официальной интеграции.

## Риски

| Риск | Влияние | Митигация на этапе discovery |
| --- | --- | --- |
| Нарушение ToS / блокировка ЛК | Высокое | Не масштабировать; держать вопрос Q4 открытым; целевой путь — API/Bitrix |
| Капча / антибот | Блок прототипа | Зафиксировано в open questions; без ручного ввода владельцем |
| Утечка секретов | Высокое | Только `.env` (gitignore); в git — `.env.example` без значений; пароли из чата **не** копировать в MD |
| Объём ~17k лотов | Время, диск, шум | Shortlist; полный dump не цель |
| Юридический / договорной | Среднее–высокое | Перед боем — согласовать с оператором или уйти на офиц. канал |

## Секреты

- Файл [`../.env.example`](../.env.example): только имена переменных.
- Реальные `ROSTENDER_USER` / `ROSTENDER_PASSWORD` — локально в `.env` (не коммитить).
- После прототипа: сменить пароль демо-доступа, если он светился вне секрет-хранилища.
