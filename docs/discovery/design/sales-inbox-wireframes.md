        └── TechRunPanel
            ├── Управление sticky (RunControls, RunQueueSummary, TechPhaseBar, TechCounters, RunReport@done)

## W-run — Вкладка «Прогон» (TO-BE, 044+)

**Order lock (designer review 2026-08-29):** Управление → **Группы** → **Площадки** → Диагностика.  
Площадки не выше групп (модель Директ: кампании, потом размещения).

```text
┌────────────────────────────────────────────────────────────────┐
│  Мониторинг тендеров     Лоты  [ Прогон ]                      │
├────────────────────────────────────────────────────────────────┤
│  УПРАВЛЕНИЕ (sticky)                                           │
│  [ Старт ]  [ Стоп ]                                           │
│  Фаза: Список · шаг 3/10 · услуги НК × РосТендер               │
│  Список 120/1000 · Карточки 8/40                               │
│  L1 12    L2 5    L3 2    noise 40                             │
│  Очередь: 5 групп × 2 площадки → 10 шагов                      │
│  (Отчёт прогона — только после завершения / остановки)         │
├────────────────────────────────────────────────────────────────┤
│  ГРУППЫ ПОИСКА                              [ Новая группа ]   │
│  услуги НК                        [в очереди ●]  Править Удал. │
│  методы                           [в очереди ●]  Править Удал. │
│  …                                                             │
├────────────────────────────────────────────────────────────────┤
│  ПЛОЩАДКИ                                                      │
│  РосТендер     [участвует ●]   сессия в порядке                │
│  Tender.Pro    [участвует ●]   вход для списка не нужен        │
│  Росэлторг     [участвует ○]   нет сессии                      │
├────────────────────────────────────────────────────────────────┤
│  ▸ Диагностика                                                 │
│    (свёрнуто; авто-раскрытие при error; лог + папка прогона)   │
└────────────────────────────────────────────────────────────────┘
```

**Управление — плотность:** phase + текущий шаг + L1 — герои; progress muted; `RunReport` не в idle/running.  
**Пока running:** Switch/CRUD групп и площадок **заблокированы**.  
**Площадки:** Switch primary; статус сессии — muted secondary (не колонка cookies).  
Drawer группы: имя · плюс · минус · лимит · в очереди — **без** площадки.  
Плюс в строке списка — не колонка (drawer / одна muted-строка под именем, clamp).

Idle empty queue (под кнопками): `Очередь пуста — включите группу и площадку` (до клика Старт).

## Interaction notes

| Action | Result |
| --- | --- |
| Click card/row | Open drawer for `tender_id`; mark interaction path for viewed (product: may auto-view on open or via footer — **footer explicit** preferred) |
| Close drawer | X / Esc / backdrop; list selection cleared |
| ViewToggle | Swap grid/table; keep filters and selection id |
| Change priority | Override chip immediately in list + drawer |
| Bitrix button | No-op; shows «Скоро» |
