├── (нет сессии) LoginScreen

    ├── AppTabs: [ Лоты* ] [ Прогон ]  + Выйти
    ├── Tab Лоты
    │   ├── InboxFilters + ViewToggle
    │   ├── LotCardGrid  XOR  LotTable

Default route/tab = **Лоты**. Без сессии Scout — **W-login**, не inbox.

│  │| вручную │□│   │| title   │□│                               │

- Popover: **Фильтры** = чекбоксы приоритета; **Срок** / **Попало** = отдельные radio-списки (не чипы). [008](../../delivery/tasks/008-filters-personal-list.md). В bar дат нет.
- Карточка: без chip Горячие/Сильные/Смотреть и без «новое»; `|` = left bar непросмотрен; «вручную» только при override; правый столбец `□` = рейл `PlatformIcon` ([011](../../delivery/tasks/011-platform-icon-rail.md)).

## Interaction notes

| Action | Result |
| --- | --- |
| Click card/row | Open drawer for `tender_id`; mark interaction path for viewed (product: may auto-view on open or via footer — **footer explicit** preferred) |
| Close drawer | X / Esc / backdrop; list selection cleared |
| ViewToggle | Swap grid/table; keep filters and selection id |
| Change priority | Override chip immediately in list + drawer |
| Bitrix button | No-op; shows «Скоро» |
