Канон **плюс-фраз** для поиска на **всех** площадках = пакеты **A–E Ростендера**. Порядок: **от сложных (точных) к простым**. Лимита 1000 нет.

**Минус-фразы** — [`search-system-v2.md`](./search-system-v2.md) (одинаковые `exclude[]` на одноимённом пакете любой ЭТП).

---

## Принципы

1. **Только открытые лоты** — приём заявок, срок подачи ≥ сегодня (МСК).
2. **Без потолка 1000** — на один точный запрос ожидаем **~30–60** строк; страховка (E) может дать больше.
3. **Несколько именованных поисков** — пакеты **A → B → C → D → E** в очереди **на каждой** площадке.
4. **Lock 034 / 041:** в query **только полные фразы**; единственная аббревиатура — **ВИК**. Усечения и прочие аббревиатуры (НК, УЗК, ПВК) **не** в сидах. Диагностирование — не query.
5. **Lock v2 (036):** у каждого поиска свой `exclude[]`; минус режет на списке.
6. **Уровень E (страховка)** — `контроль сварных соединений` + `сварных соединений`.
7. **Стилоскопирование / профильный / радиационный** — **не** отдельные query; только правила оценки.
8. **Имя поиска** = `{Площадка} — {уровень}` (напр. `Tender.Pro — методы`). `queries` / `exclude` **не** зависят от площадки.

## Уровни фраз (плюс) — SoT

| Уровень | Смысл | Фразы (плюс) |
| --- | --- | --- |
| **A — услуга целиком** | Явная работа НК | неразрушающий контроль · дефектоскопия |
| **B — метод как работа** | Конкретный вид контроля | ультразвуковой контроль · визуально-измерительный контроль · капиллярный контроль · радиографический контроль · гаммаграфический контроль · толщинометрия ультразвуковая |
| **C — аббревиатуры** | Короткие запросы | **ВИК** (единственная аббревиатура) |
| **D — контроли** | Приёмка / стройконтроль | принимающий контроль · приёмочный контроль · входной контроль · **строительный контроль** |
| **E — страховка** | Широко | контроль сварных соединений · сварных соединений |
| *(не query)* | Только правила | стилоскопирование · профильный контроль · радиационный |

## Пакеты именованных поисков (все ЭТП)

Одинаковые `queries[]` / `exclude[]` на rostender, tender-pro, roseltorg (и будущих ЭТП через ту же фабрику).

| Уровень | Суффикс имени | `queries[]` | `exclude` (кратко) |
| --- | --- | --- | --- |
| A | услуги НК | как SoT A | supply: поставка, закупка, прибор |
| B | методы | как SoT B | supply |
| C | аббревиатуры | `["ВИК"]` | supply |
| D | контроли | как SoT D | social D + supply |
| E | страховка | как SoT E | supply |

Примеры имён: `РосТендер — услуги НК`, `Tender.Pro — услуги НК`, `Росэлторг — услуги НК`.

Код: [`app/worker/search_seeds.py`](../../app/worker/search_seeds.py) → `seeds_for_platform` / `search_seed_rows`.

## Обработка внутри одного поиска (v2)

```text
queries[] (плюс)
  → union по native id
  → exclude[] (минус) по title — drop до скоринга
  → без обрезки limit_n
  → скоринг → L1 / L2 / L3
  → ingest на доску
  → ИИ — отдельным шагом
```
