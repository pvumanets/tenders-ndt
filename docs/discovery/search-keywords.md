# Ключевые слова поиска и стратегия

**status:** active  
**last-review-date:** 2026-08-28  
**owner lock:** [`owner-decisions.md`](./owner-decisions.md) (2026-08-27, волна 2)  
**методы (глоссарий):** [`../company/ndt-methods.md`](../company/ndt-methods.md)  
**очередь прогонов:** [`named-searches.md`](./named-searches.md)

Канон фраз для **поиска на площадках**. Порядок: **от сложных (точных) к простым (коротким и широким)** — страховка в конце очереди. Лимита 1000 нет.

---

## Принципы

1. **Только открытые лоты** — приём заявок, срок подачи ≥ сегодня (МСК). Прошлое и закрытое не ищем ([019](../delivery/tasks/019-open-upcoming-only.md)).
2. **Без потолка 1000** — на один точный запрос ожидаем **~30–60** строк; страховка (E) может дать больше — это ок.
3. **Несколько именованных поисков** — пакеты по уровням **A → B → C → D → E** в очереди.
4. **Lock 034 (2026-08-28):** в query Rostender **только полные фразы**; единственная аббревиатура — **ВИК**. Усечения (`ультр.`, `нераз.`, …) и прочие аббревиатуры (НК, УЗК, ПВК) **убраны**. Диагностирование — не query.
5. **Уровень D** (четыре контроля) — **в поиске**, отдельным пакетом.
6. **Уровень E (страховка)** — `контроль сварных соединений` + `сварных соединений`; без диагностики.
7. **Стилоскопирование / профильный / радиационный** — **не** отдельные query; только правила оценки.

## Уровни фраз (слож → прост / широко)

| Уровень | Смысл | Фразы |
| --- | --- | --- |
| **A — услуга целиком** | Явная работа НК | неразрушающий контроль · дефектоскопия |
| **B — метод как работа** | Конкретный вид контроля | ультразвуковой контроль · визуально-измерительный контроль · капиллярный контроль · радиографический контроль · гаммаграфический контроль · толщинометрия ультразвуковая |
| **C — аббревиатуры** | Короткие запросы | **ВИК** (единственная аббревиатура, lock 034) |
| **D — контроли** | Приёмка / стройка (в поиске) | принимающий контроль · приёмочный контроль · входной контроль · строительный контроль |
| **E — страховка** | Широко | контроль сварных соединений · сварных соединений |
| *(не query)* | Только правила | стилоскопирование · стилос. · профильный контроль · профил. · радиационный · радиац. |

## Пакеты именованных поисков (целевые сиды)

После синхронизации кода — заменить один seed «неразрушающий».

### РосТендер (`rostender`)

Каждая строка `queries[]` = поле `keywords` на площадке. **Полные + усечения** в одном пакете.

| Имя поиска (человеческое) | Уровень | Пример `queries[]` | В очереди |
| --- | --- | --- | --- |
| РосТендер — услуги НК | A | `["неразрушающий контроль", "дефектоскопия"]` | да, **1** |
| РосТендер — методы | B | `["ультразвуковой контроль", "визуально-измерительный контроль", "капиллярный контроль", "радиографический контроль", "гаммаграфический контроль", "толщинометрия ультразвуковая"]` | да, **2** |
| РосТендер — аббревиатуры | C | `["ВИК"]` | да, **3** |
| РосТендер — контроли | D | `["принимающий контроль", "прин.", "приёмочный контроль", "входной контроль", "строительный контроль"]` | да, **4** |
| РосТендер — страховка | E | `["контроль сварных соединений", "сварных соединений"]` | да, **5** (последним) |

Внутри одного поиска: длинные фразы раньше усечений/аббревиатур.

### Tender.Pro (`tender-pro`)

Каждая строка = `good_name` (поле «товар» в адаптере).

| Имя | `queries[]` |
| --- | --- |
| Tender.Pro — методы | `["ультразвуковой контроль", "визуально-измерительный", "капиллярный", "радиографический"]` |
| Tender.Pro — аббревиатуры | `["ВИК", "ПВК", "УЗК", "НК"]` |

## Обработка внутри одного поиска

```text
queries[] (порядок: длинные → короткие)
  → union по native id площадки
  → dedup
  → без обрезки limit_n (продуктовый lock 2026-08-27)
  → скоринг по правилам → L1 / L2 / L3
  → ingest на доску (все три тира — см. owner-decisions)
  → ИИ — отдельным шагом (разбирает мусор страховки)
```

**Код (030 + 033 + 034):** `limit_n=0`; RT A–E полные фразы + только ВИК (миграция `0009`); TP без изменений.

## Почему убрали лимит 1000

| Было | Стало |
| --- | --- |
| Страх «скачать слишком много» | Фильтр «только открытые с сегодня» уже режет прошлое |
| Первые query съедали лимит, хвост голодал | Отдельные поиски A–E; без потолка |
| ~1000 в каноне Q1 | Без лимита; страховка E намеренно шире |
