## 1. Поиск (Все тендеры)

| Элемент | Наблюдение |
| --- | --- |
| URL | `/extsearch?query=…` (хэш шаблона/сессии) |
| Вкладки | **ПРОСТОЙ** / **РАСШИРЕННЫЙ** |
| Фильтры | Регион, Отрасль |
| Поле поиска | «Поиск во всех тендерах» |
| Действие | кнопка **Искать** |
| Опция | «Искать в документах» |
| Шаблоны | «Сохранить шаблон» → раздел «Мои шаблоны» |
| Выгрузка списка | «Сохранить в Excel» (над таблицей) |
| Сортировка | «сначала новые» (`sort=0`) — канон P1 |
| Этап (P1) | только **Приём заявок** (`states[]=10`); не Завершён / Отменён |
| Срок подачи (P1) | `dte_from` = сегодня МСК; прошлое не берём |
| Левое меню | Все тендеры, Мои тендеры, Мои шаблоны, Избранное, Просмотренные, … |

**Прототипный запрос владельца:** `неразрушающий`. Без фильтра этапа на скрине ~17k (архив). Живой прогон 2026-08-13: **43** открытых (приём заявок, срок ≥ сегодня).

## 3. Карточка тендера

Пример пути: `/region/{region}/{city}/{id}-tender-…`

| Блок | Поля для сбора |
| --- | --- |
| Шапка | № тендера, дата, статус (напр. «Приём заявок»), заголовок |
| Цена | Начальная цена |
| Место | Место поставки (город, субъект) |
| Заказчик | Наименование; на карточке также ИНН / КПП |
| Сроки | До окончания приёма; окончание MSK |
| Участие | Способ (напр. запросы котировок); ссылка на исходную ЭТП (напр. ТЭК-Торг + ID); окна подачи / итогов |
| Документация | Файлы, «Скачать одним архивом» |
| Контакты | ФИО, телефон, email |
| Навигация справа | Описание, Реквизиты, Позиции, Участники, Похожие |

## 5. Пробелы карты

- Пагинация / бесконечный скролл — не описаны.
- Экран логина / капча / 2FA — не снимались; владелец: капчу вводить не должен.
- Поведение «Сохранить в Excel» при большом объёме — неизвестно.
