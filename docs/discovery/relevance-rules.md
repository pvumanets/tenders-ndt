## Цель

Отделить **услуги НК** от закупок приборов. География: **вся РФ**.

## Поиск (v0)

| Запрос | Сортировка | Пул |
| --- | --- | --- |
| `неразрушающий` (+ канон фраз в search-keywords) | сначала новые | **открытые** (Приём заявок, срок ≥ сегодня МСК), **без лимита** (~30–60 на запрос) |

## Тиры

| Тир | Куда | Карточка |
| --- | --- | --- |
| L1 / L2 / L3 | `priority-fit.md` + колонка в реестре | да |
| `noise` | реестр | нет |
| `pool` | реестр (прочие из выдачи) | нет |

Детали порогов — [`fit-tiers.md`](../delivery/fit-tiers.md).

## Include

- НК, **радиограф / рентген / гаммаграф / ЦР**, ВИК, ПВК как услуги;
- **УЗК/УЗТ как услуги** — забираем (решение владельца 2026-08-11; **033:** аббревиатура **УК** в названии компании ≠ ультразвук);
- контроль сварных соединений как работы НК;
- проведение / оказание услуг контроля.

## Exclude → noise

- закупка/поставка приборов и оборудования НК;
- поверка/ремонт СИ без услуг на объекте;
- только расходники;
- обучение/аттестация как основной предмет.

## Скоринг (ориентир)

| Балл | Условие |
| --- | --- |
| +4 | УЗК/УЗТ как работы (не `\bук\b` в «ООО УК …») |
| +3 | Услуга НК / радиограф·рентген·ЦР/ВИК/ПВК явно (не `\bрк\b` в госномере) |
| +2 | Метод + объектный контекст |
| +1 | Нефтегаз / энергетика / стройка / ВПК |
| −3 | Закупка приборов |
| −2 | Расходники / поверка без услуг |
| −1 | Общий «неразрушающий» без предмета |

Маппинг score → L1/L2/L3 — в fit-tiers. Дообучение после первых выгрузок.
